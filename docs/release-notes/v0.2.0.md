The first published build of zen-linear, a terminal client for Linear.

## What it does

**Three panes.** Your teams and the favorites from Linear's sidebar on the left,
the issue list in the middle, the issue itself on the right. `?` lists every key
that works where you are.

**The issue list** groups, subgroups, sorts and filters, and the columns are
yours to pick and order. Search is workspace-wide, from the navigation pane.

**Issues are edited in place.** A cursor walks the metadata rows and Enter opens
the field's options under it. Title, due date, estimate and the description are
typed where the value already sits, and labels toggle in the same list.

**Comments read as a conversation.** Replies nest under what they answer, the
issue's activity is folded in by time, and your own comments can be edited or
deleted. A reply is written inside the thread it belongs to.

**It reopens where you left it.** The workspace, the place in the tree, the
issue, the filters and the search are kept between runs, and the tree is painted
from disk so a launch is not blank while it loads.

**More than one workspace**, each reading its API key from an environment
variable you name, switched with `w`.

**Five themes**, defaulting to your terminal's own colors.

**An agent can be sent at an issue**, through the Claude or Cursor CLI if you
have one installed.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.sh | sh
```

macOS and Linux, arm64 and amd64. The binary lands in `~/.local/bin`, and the
download is checked against the release's checksums before it is installed.

Windows takes the `.zip` from this page, the installer being a POSIX script.
Anything else builds with `go install
github.com/praxis-labs-io/zen-linear/cmd/zen-linear@latest`.

Then authenticate:

```sh
zen-linear auth login
```

[Install and auth in full](https://github.com/praxis-labs-io/zen-linear/blob/main/docs/install.md),
and [the guide](https://github.com/praxis-labs-io/zen-linear/blob/main/docs/guide.md)
for what the panes do.

## Known gaps

- There is no Homebrew tap.
- Windows has no installer script, and is untested beyond the build.
- Agent runs need the provider's CLI on your PATH. Nothing is bundled.
