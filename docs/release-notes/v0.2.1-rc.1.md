A release candidate with nothing in it for users. It exists to run the release
workflow after its actions were bumped, before a real release does.

## Changed

**The release workflow's actions.** `checkout` and `setup-go` to v7,
`upload-artifact` to v7, `download-artifact` to v8. The first two were the Node
20 deprecation; the artifact pair had drifted three and four majors behind.

`download-artifact` v8 is the reason this candidate exists. It errors on a hash
mismatch where it used to warn, and it no longer unzips everything, reading
`Content-Type` first. The release job collects five archives with
`merge-multiple: true` and checksums them, which is the path both changes run
through, and a failure there would land after a permanent tag on a real release.

**CI's actions**, the same deprecation, and `golangci-lint` and `codecov`
brought current.

Everything else in the range is a comment and a doc correction.

## Install

Do not. This is a pre-release: it is not the latest release, and the installer
will not offer it.

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.sh | sh
```

still gets you v0.2.0, which is what you want.
