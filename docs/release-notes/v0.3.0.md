The navigation tree reshaped around how Linear's own sidebar reads, and the
config and logging paths made honest on machines that are not the one they were
written on.

## New

**The tree has sections.** All Issues, then Favorites in the order you keep
them, then Teams, with a blank row between. The headings are labels rather than
rows, so the cursor steps over them, and a section with nothing in it is left
out.

**A team folds.** A team's row only opens and closes, so folding one costs no
fetch. It opens onto its All Issues and three headings of its own, Cycles,
Status and Projects, each folded. The folder icon on a row says which way it
goes.

**Favorites move with `J` and `K`.** A favorite steps through the tree as it is
drawn: onto an open folder moves it in, off the end of a folder moves it back
out, and a closed folder is stepped over. A folder moves whole. All of it
writes back to Linear, so the web app stays in step.

**A favorited project lists every team's issues.** The favorite is the project,
not one team's slice of it. A team can be favorited too, and opens onto its own
All Issues.

**The six documented environment variables work.** `LINEAR_API_ENDPOINT`,
`LINEAR_TIMEOUT`, `LINEAR_PAGE_SIZE`, `LINEAR_CACHE_TTL`, `LINEAR_LOG_FILE` and
`LINEAR_LOG_LEVEL` override the config file. They were documented and inert.
A field an environment variable holds is shown, locked in the settings modal,
and never written back to `config.json`.

## Fixed

**A shared config file no longer breaks a second machine.** `log_file` was
saved as a resolved path, so a `config.json` synced through a dotfiles repo
carried one machine's home directory to another, where the directory could not
be created. It is now resolved per machine, and a path equal to the machine's
default is not written out at all.

**A log that cannot be opened no longer kills the launch.** It falls back to the
default path, then to no logging, and says which in the app. The setting that
caused it lives in a modal the app never used to reach.

**The log stops growing.** It is capped at 5 MB, past which it is moved to
`app.log.1`, replacing any earlier one. A relaunch counts from the size on
disk rather than from nought.

**A link in a description no longer underlines the rest of the details pane.**
The underline an issue's first link opened ran down every row under it, through
the rules, the comment cards and the compose box. Links are marked by color.

## Changed

**`~/.zen-linear` is 0700.** It holds `credentials.json`, and four writers used
to race to create it, three of them at 0755. A directory an older build left
open is tightened. A `config.json` under `$XDG_CONFIG_HOME` is left alone: that
one is usually a dotfiles checkout.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.sh | sh
```

macOS or Linux, on arm64 or amd64. Windows takes the archive from the releases
page. The binary lands in `~/.local/bin`, which some shells do not carry on
PATH; the installer says so if yours does not.

The tree's icons need a [Nerd Font](https://www.nerdfonts.com). Without one
they draw as empty boxes, and nothing else depends on it.
