This release fixes the Windows installer and reworks the settings form.

## Changed

**The settings form is sectioned.** Appearance, Startup, Agents, Network and
Logging are listed down the left of it, one shown at a time. That list holds the
keyboard with `j`/`k` or the arrows, `⏎` crosses into the fields, and Save and
Cancel sit under the sections rather than past every field in the open one. Esc
goes back to the list before it closes the form, and the panel no longer resizes
as you step between sections. A panel too narrow for the column names the open
section on one line instead.

## Fixed

**The Windows installer no longer closes your terminal.** `irm | iex` runs the
script in your own session, so a failed install ended the session with it. It
throws instead, and its error preference and strict mode end with the install
rather than staying in your session. It no longer narrows the TLS protocols
that session allows either.

**The PATH line the installer prints is right.** It pasted the whole process
PATH into your user PATH, which wrote entries that belonged to the session into
your account and lost anything the session had not picked up. It appends to the
user PATH it reads back now.

**A 32-bit PowerShell takes the right binary.** A 64-bit Windows running the
32-bit host reported x86, and the install refused a platform it has a binary
for.

**The download is no longer slowed by its own progress bar.** PowerShell 5.1
spends more on drawing one than on the transfer. 5.1 is what ships with Windows
and what `irm | iex` reaches.

**A failed release lookup says why.** Inside the error switch `$_` was the
status code rather than the error, so a lookup that could not reach GitHub
printed an empty reason.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.sh | sh
```

macOS or Linux, on arm64 or amd64. Windows:

```powershell
irm https://raw.githubusercontent.com/praxis-labs-io/zen-linear/main/install.ps1 | iex
```

Already running zen-linear: `zen-linear update`.

On macOS and Linux the binary lands in `~/.local/bin`, which some shells do not
carry on PATH. On Windows it lands in `%LOCALAPPDATA%\Programs\zen-linear`.
Either installer says so when the directory is not on your PATH, and neither
edits it for you.

The tree's icons need a [Nerd Font](https://www.nerdfonts.com). Without one they
draw as empty boxes, and nothing else depends on it.
